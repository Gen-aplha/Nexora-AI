🌟 About NEXORA AI

NEXORA AI is a modern AI assistant project built to provide an accessible and user-friendly AI experience.

Whether you want to ask questions, explore ideas, generate images, work with documents, or have an AI-powered conversation, NEXORA AI brings these capabilities together in one place.

The project focuses on simplicity, useful features, and a clean user interface.

✨ Features

- 🤖 AI Conversations – Chat with an AI assistant and get helpful responses.
- 📝 Markdown Formatting – Read formatted responses with headings, lists, bold text, and code blocks.
- 💬 Chat History – Save and revisit previous conversations.
- 🎙️ Voice Input – Use voice recognition to enter messages where supported.
- 🔊 AI Voice Responses – Listen to AI responses with text-to-speech.
- 🎨 AI Image Generation – Create images using text prompts.
- 📎 File Attachments – Work with supported images and documents.
- 🖼️ Image Downloads – Download generated images.
- 🌙 Dark and Light Themes – Choose your preferred appearance.
- 📱 Android App – Check the GitHub Releases page for available APK versions.
